# 데모 진행 순서

1. `.env`에 OpenAI API 키를 설정한다.
2. `python scripts/collect_data.py`로 공식 법령 조문을 수집한다.
3. 생성된 JSONL 파일과 조문 수를 확인한다.
4. `python scripts/build_index.py`로 임베딩 및 ChromaDB 저장을 수행한다.
5. `uvicorn app.main:app --reload`로 서버를 실행한다.
6. 브라우저에서 근로계약서, 임금, 근로시간, 연차, 해고 관련 질문을 입력한다.
7. 답변 내용과 함께 표시되는 조문 번호·원문 발췌·공식 출처 링크를 확인한다.
8. `python scripts/evaluate.py`를 실행해 Recall@5와 MRR@5를 기록한다.
9. chunk 설정을 변경해 재색인한 뒤 동일 평가 세트로 개선 여부를 비교한다.

## 시연 질문

- 근로계약서를 작성할 때 명시해야 하는 내용은?
- 임금은 어떤 원칙으로 지급해야 하나요?
- 근로시간과 휴게시간의 기본 기준은 어떻게 되나요?
- 연차 유급휴가는 어떻게 보장되나요?
- 해고할 때 지켜야 할 절차는?

## 시연 시 확인할 항목

- 질문이 실제 API에 전달되는가
- 답변이 검색된 문맥을 벗어나지 않는가
- 답변과 함께 조문 출처가 표시되는가
- 근거가 없을 때 확인 불가로 응답하는가
