# 검색 평가 및 개선

## 평가 데이터와 지표
data/evaluation/questions.json의 자연어 질문과 기대 조문 라벨을 오프라인 평가에 사용한다.
- Recall@K: 상위 K개 검색 결과에 기대 조문이 포함된 질문 비율
- MRR@K: 첫 관련 조문 순위의 역수 평균. 관련 조문 미검색은 0
- K: RETRIEVAL_TOP_K 환경 설정
- 실행: python scripts/evaluate.py

## 개선 실험
1. 현재 CHUNK_SIZE, CHUNK_OVERLAP, RETRIEVAL_TOP_K 설정으로 기준 점수를 측정한다.
2. 청킹 크기 또는 overlap 중 한 항목만 변경한다.
3. 전체 문서를 다시 인덱싱한다.
4. 동일 평가 질문으로 재평가한다.
5. 실제 출력값을 기록하고 기준보다 향상된 지표와 부작용을 함께 비교한다.

| 실험 | chunk_size | overlap | top_k | Recall@K | MRR@K |
|---|---:|---:|---:|---:|---:|
| 기준 | 설정값 | 설정값 | 설정값 | 측정 후 기록 | 측정 후 기록 |
| 개선 | 변경값 | 변경값 | 설정값 | 측정 후 기록 | 측정 후 기록 |

## 한계
- 소규모 평가 질문으로 실제 사용자 질문 분포를 대표하지 못한다.
- 검색 지표는 검색 품질만 측정하며 답변의 법률적 정확성을 직접 평가하지 않는다.
- 근로기준법 외 시행령·시행규칙·판례·행정해석은 포함하지 않는다.
- 공식 HTML 구조 변경 시 수집기 수정이 필요하다.
- 법령 개정 시 재수집과 재색인이 필요하다.
- 본 서비스는 학습·정보 탐색용 POC이며 법률 자문이 아니다.
