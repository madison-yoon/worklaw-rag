# 검색 평가 및 개선

## 평가 데이터

`data/evaluation/questions.json`에 MOMO 영화 리뷰 검색 질문 8개와 기대 리뷰 ID를 저장한다. 평가 라벨은 오프라인 평가에서만 사용하며 서비스 질문·검색·답변 경로에는 전달하지 않는다.

## 지표
- **Recall@K:** 상위 K개 검색 결과에 기대 리뷰가 하나 이상 포함된 평가 질문 비율
- **MRR@K:** 각 질문에서 첫 번째 기대 리뷰가 등장한 순위의 역수 평균. 미검색은 0
- K는 `RETRIEVAL_TOP_K` 설정을 사용한다.
- 실행: `python scripts/evaluate.py`

## 개선 실험 절차
1. 초기값(chunk_size=500, overlap=80, top_k=5)으로 기준 검색 결과와 지표를 측정한다.
2. 청킹 크기를 350자로 변경하고 overlap은 60자로 설정한다.
3. 전체 리뷰를 재색인한다.
4. 동일한 8개 질문으로 Recall@K와 MRR@K를 다시 측정한다.
5. 기준과 개선 결과를 표에 기록하고 질문별 검색 순위 변화도 확인한다.

| 실험 | chunk_size | overlap | top_k | Recall@5 | MRR@5 |
|---|---:|---:|---:|---:|---:|
| 기준 | 500 | 80 | 5 | 실제 측정값 기록 | 실제 측정값 기록 |
| 개선 | 350 | 60 | 5 | 실제 측정값 기록 | 실제 측정값 기록 |

점수는 Atlas 검색 인덱스와 임베딩 실행 결과를 측정한 뒤 기록한다. 실행하지 않은 수치를 임의로 기재하지 않는다.

## 한계
- 리뷰 10건·영화 5편으로 구성된 소규모 시연 데이터다.
- 리뷰는 가상 감상이며 실제 사용자 취향이나 대중 평가를 대표하지 않는다.
- Recall/MRR은 검색 결과의 적합성을 측정할 뿐 답변의 사실성·유용성을 직접 평가하지 않는다.
- 영화의 객관적 사실, 줄거리 전문, 흥행 정보는 데이터에 없으며 답변 범위 밖이다.
- Atlas 검색과 OpenAI 호출에는 네트워크 및 사용료가 필요하다.
- MOMO 본 서비스의 로그인·권한·MySQL과 독립 실행형 POC는 연결되어 있지 않다.
