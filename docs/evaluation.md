# 검색 평가 및 개선

## 평가 데이터
data/evaluation/questions.json의 8개 질문과 기대 리뷰 ID를 사용한다. 질문은 영화별 긍정·비판 감상, 음악·연출·촬영 등 검색 의도를 포함한다. 라벨은 평가에만 사용한다.

## 지표
- Recall@K: 상위 K개 결과에 기대 리뷰가 하나 이상 포함된 질문 비율
- MRR@K: 첫 번째 기대 리뷰가 검색된 순위의 역수 평균
- 실행: python scripts/evaluate.py

## 개선 실험
1. 기준 설정 500자/80자, top-k 5로 지표를 측정한다.
2. 청크 크기 350자, overlap 60자로 변경한다.
3. 전체 문서를 재색인하고 동일 질문으로 다시 측정한다.
4. Recall@5, MRR@5와 질문별 검색 순위를 비교한다.

실제 측정 전 수치를 임의로 기록하지 않는다.

## 추천 기능 평가
MOMO 추천 후보 API는 기존 박스오피스 이력·장르 필터를 그대로 사용한다. AI 추천 설명은 검색된 영화·리뷰 근거만 사용한다. 추천 후보 적합성은 5개 이상 사용자 시나리오에서 장르 일치, 근거 리뷰 포함, 중복 추천 여부를 수동 확인해 기록한다.

## 한계
- 리뷰 10건은 가상 시연 데이터이며 실제 회원의 평가 분포를 반영하지 않는다.
- MOMO 추천 후보가 비어 있으면 박스오피스 이력 수집 상태에 영향을 받은 것이다.
- Recall/MRR은 검색 품질 지표이며 생성 답변의 정확성을 직접 보증하지 않는다.
- 소규모 평가 질문 8개로 일반화할 수 없다.
