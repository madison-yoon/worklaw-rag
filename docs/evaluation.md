# 검색 평가 및 개선

## 평가 데이터와 지표
data/evaluation/questions.json의 질문 및 기대 조문 라벨을 사용한다.
- Recall@5: 상위 5개 결과에 기대 조문이 하나 이상 포함된 질문 비율
- MRR@5: 첫 관련 조문 순위의 역수 평균. 미검색은 0
- 실행: python scripts/evaluate.py

## 개선 실험
1. 기준 설정 chunk_size=500, overlap=80으로 전체 문서를 인덱싱하고 평가한다.
2. chunk_size=700, overlap=100으로 변경하고 반드시 전체 재인덱싱한다.
3. 동일 질문 세트로 재평가해 Recall@5와 MRR@5를 비교한다.
4. 실제 출력값만 아래 표에 기록하고 결과가 좋아졌을 때만 개선으로 판단한다.

| 실험 | chunk_size | overlap | top_k | Recall@5 | MRR@5 |
|---|---:|---:|---:|---:|---:|
| 기준 | 500 | 80 | 5 | 측정 후 기록 | 측정 후 기록 |
| 개선 | 700 | 100 | 5 | 측정 후 기록 | 측정 후 기록 |

## 한계
- 평가 질문 5개로 실제 사용자 질문 분포를 대표하지 못한다.
- 검색 지표는 검색 품질만 측정하며 답변의 법률적 정확성을 직접 평가하지 않는다.
- 근로기준법 중심으로 시행령·시행규칙·판례·행정해석을 포함하지 않는다.
- 공식 HTML 구조 변경 시 수집기 수정이 필요하다.
- 법령 개정 시 재수집과 재색인이 필요하다.
- 본 서비스는 학습·정보 탐색용 POC이며 법률 자문이 아니다.
